업무 관리 사용 가이드

조회는 자유롭게, 수정 후에는 꼭 저장해 주세요.

  1. 업무 공간 선택

    CX · 기업 · 알닷 중 담당 업무 공간을 선택하세요. 로그인 없이 업무와 수정 이력을 볼 수 있습니다.

  2. 로그인 후 작성·수정

    관리자·편집자 계정으로 로그인하면 새 업무를 추가하거나 표의 내용을 수정할 수 있습니다. 새 업무는 작업자와 업무제목을 모두 입력하세요.

  3. 변경 후 저장 버튼 클릭

    작성·수정·이월한 내용은 저장 버튼을 눌러 반영하세요. 재이월하면 원래 달의 내용으로 기존 이월 업무를 덮어쓰며 작업시간·조정은 비워집니다. 삭제는 확인 즉시 현재 변경 내용과 함께 저장됩니다. 저장 완료 문구를 확인한 뒤 페이지를 닫으세요. 저장 실패 시 입력 내용을 확인하고 다시 저장해 주세요.

  4. 월·검색·필터로 찾기

    월을 이동하거나 업무명·작업자·RMS를 검색하세요. 진행중 / 전체 탭과 작업자·단계 필터로 목록을 좁힐 수 있습니다.

  5. 반영 일정 확인

    검수요청 단계에서는 운영 반영일 칸이 분홍색으로 표시됩니다.

  6. 이력 확인과 CSV 저장

    수정 이력에서 수정자와 변경 내용을 확인하세요. CSV 저장은 현재 검색·필터가 적용된 표를 내려받습니다. 최신 목록은 새로고침(↻)으로 확인하세요.
